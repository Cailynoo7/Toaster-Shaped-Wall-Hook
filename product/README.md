# 卡通吐司机挂钩 v42

以用户参考图为唯一外观依据，奶油色圆角机身、金色底座与旋钮、浅灰面板、三按钮、侧面拨柄、双色吐司和无眉毛圆眼表情。纯机械，无电子板。

## 尺寸与形态
用户要求长度缩到8，按盒子本体横向长度8cm理解，由128mm同比缩至80mm，比例62.5%。全部零件几何、厚度、孔径、间隙、圆角、机关尺寸和装配坐标同步缩放，角度和无量纲轮廓系数不变。盒子名义横宽80mm；底盘延续机身斜面后实际最大尺寸约80.1346×41.25×57.5mm，上部名义宽75、下宽80，正面轻微梯形，侧面矩形并延续圆角。前后边界y=-23.125至18.125，中心y=-2.5与面包居中。前后加厚量等比为5mm。

吐司名义50×8.75×48.125mm，米色完整主体、周圈烘焙色面包皮。外皮边框1.25mm、极值胶接间隙0.09375mm。顶冠保持认可的饱满圆拱，中间贯穿前后凹槽深0.34375mm、半宽1.125mm、槽口圆角R0.625mm；前后边缘软化0.5mm。左右竖直边镜像对齐，每侧外拱0.625mm，曲率从顶端到底部圆角前小幅大—小—大。无眉毛，圆眼半径2.1875mm。

挂钩12mm原宽等比为7.5mm、杆厚3.125mm，长度参数54.375mm；空载钩尖至盒子底面名义空位12.5mm，承重时33.75mm。顶部槽沿57.5×16.25×0.75mm，开口53.75×12.5mm，边宽1.875mm，圆角0.1875mm；PLA金属灰打印装饰。

## 运动与安装
挂物使挂钩下移、等臂摇杆顶起吐司，取下物品靠吐司自重复位。行程21.25mm；摇杆轴心(0,10,21.875)，臂长18.75mm，角度±34.51810784度。空载吐司基准z22.5，升起z43.75；挂钩滑块中心由z32.5降至z11.25。保持相对连接及运动关系。平背墙面承重胶粘。

## 制作默认值与验收
PETG机构、PLA吐司及装饰。0.2mm层高、0.4mm喷嘴，机构至少5道壁和100%填充；打印配置没有当作几何尺寸同比缩放。轴径3.75mm、孔4mm，导轨每侧间隙0.3125mm，挂钩穿底座每侧0.1875mm。先试打配合，清理支撑后装配，胶固轴帽但不粘住摇杆，面包皮和米色主体点胶固定，背板与底板用卡扣锁止，墙面胶须匹配墙材。500g仍为未经验证的默认目标；启动力、摩擦、复位、疲劳和承重需实物验证。

验收为外观与两端几何配合，交付STEP静态分件装配。每次用户修改递增版本并同步模型、需求、零件清单和说明；下次为v43。

背部先按完整梯形外轮廓和圆角建模，再用同一Y平面切分出背板；默认切分中心y16.25mm、接缝0.1875mm，两半各让0.09375mm。背板内部机关、舌边、轴和导轨位置保持，背面外轮廓与壳体一致。

背板与机身采用4处弹性卡扣，底板与机身采用2处弹性卡扣；PETG悬臂厚1.2mm、背板长度8.2mm、底板长度9.6mm、扣宽5mm，名义啮合0.4mm、轴向余隙0.2mm。底板两个3×1.2mm解扣入口内收至底面y-19.5，通过斜通道连至卡舌侧y-21.1，供薄片向内压舌解锁，拆底板后从内部按压背板卡舌再退出。卡紧力和反复拆装寿命须试打检验。
控制面板、旋钮、按钮保留上移4mm的位置。底板外缘高8.375mm、底面z0不变；内部整体内凹6.5mm，底面与周边名义壁厚均为1.875mm，与机身一致。取消后方两个独立机关凹坑，后周壁连续。后侧两只刚性插舌先插入背板承口，前侧两只从薄底面生根的弹性卡扣按下锁止；前扣尖降至z11.275mm，避开旋钮止退帽。导轨止挡低位后沿修至y16.05，与托盘后内壁留0.2mm；机关滑动面、轴心、面包位置及21.25mm行程保持。

前旋钮为可自由旋转装饰，采用3mm一体轴与3.4mm滑动孔、内侧PETG止退帽胶固。手柄默认宽2.2、厚约2.2667、高10mm，与圆盘连接处直角，侧边圆角R0.45mm，外露前边软化R0.375mm。周围雕刻225度起顺时针跨270度的圆弧，六个大刻度及数字1–6，等距54度，每两大刻度之间4个小刻度，共20个；数字正立、字号2.4mm，槽深0.65mm，嵌件厚0.8mm，表面凸出0.25mm。刻度和数字为独立深棕色PLA嵌件。旋转顺滑程度、打印孔配合与胶固止退需试打验证。

嵌件组共32件：6大刻度、20小刻度、数字1–6各1件。刻度配薄锁边和槽内扩口，名义倒扣每边0.02mm；导入间隙每边0.08mm，底部间隙0.1mm。数字不做内扩锁边以保护面板封闭数字的细柱，必要时微量胶固定。小刻度略加宽至0.5×0.65mm，大刻度0.6×1mm，便于打印装配。推荐嵌件使用0.2mm喷嘴、0.1mm层高，正面朝下打印，按编号与角度对应压入；孔槽及锁边实际松紧必须试打确认。

右侧三按钮侧面轮廓圆角增至R2.34375mm、前沿圆角R1.171875mm，均为原值的1.5倍；背面贴合边和榫根不倒圆。各按钮上方从左至右为REHEAT、CANCEL、DEFROST，Arial Bold字号1.8mm，字形槽深0.65mm，中心z24.4mm。独立面板圆角边框删除，浅灰面板本体保留。

三个按钮改为装入面板与机身阶梯浅槽：按钮平肩嵌入0.35mm，背面一体定位榫4.8×5.1125mm、长1.25mm、轮廓R1.4mm，穿过面板进入壳体。机身槽深0.575mm，座孔与榫每边间隙0.1mm，榫底留0.1mm，必要时极微量胶固定；实际打印配合需试打。前部保留约1.525mm凸起厚度，三个英文的位置保持。

三个英文配19个独立字母嵌件，字号保持1.8mm、厚0.8mm、凸出0.25mm，槽位每边间隙0.06mm、底隙0.1mm；用镊子逐字插入。小字采用0.2mm喷嘴、0.1mm层高先试打，若松动可微量胶固定。底座外沿上边不倒圆，下周边圆角增至R2.8125mm（原R0.9375mm的三倍）。側圆钮背部平整无圆角，对应机身圆浅槽半径4.475mm、深0.5mm，嵌入0.4mm，底隙0.1mm。四只金色脚顶部无圆角、下边圆角R1.0625mm保持，对应底盘浅槽半径3.5375mm、深0.5mm，嵌入0.4mm；中心x±26.875、y-16.5/11.5、z-0.85，围绕底盘中心y-2.5对称。脚与侧钮保持装饰胶接。

底盘左右斜壁延续机身侧面同一平面，每侧水平变化/竖向高度为4/85，倾角2.6942843度，z8.375接缝上口宽79.6235mm，接缝无外凸台阶。底盘实际最大宽约80.1346mm。内侧斜壁平行外壁，名义法向壁厚1.875mm，外缘顶部保持直角。前后脚及浅槽各向中心内移1.3125mm，保持中心y-2.5对称，避免0.5mm浅槽开到大圆角边缘。

挂钩外露J形钩体整体倒圆：长杆、弯曲段及钩尖周边均采用R1.5mm，为原R0.75mm的两倍；挂钩长度参数54.375mm、宽7.5mm、厚3.125mm，以及内部滑块销槽和导轨配合保持。

底盘采用梯形截面拉伸产生斜壁，四角以标准R6.25mm圆柱曲面连接，底部R2.8125mm保持。内腔底面为水平平面，和侧壁之间R0.4mm相切过渡，主体底厚1.875mm。两处小孔用于卡扣拆卸，入口收在底面、不切断外侧底圆角；实际拆装工具和卡扣力需试打。

背板上方四个止挡肩向外加宽，与侧面长导柱外沿齐平并直接连接；每肩宽由1.875mm增至4.0625mm，高3.75mm、前后深4.5625mm，底面z36.25、顶面z40保持，中间滑块颈部开口7.5mm保持。加宽部分不占用滑动通道，原21.25mm运动行程不变；实际限位抗冲击强度需实物试验。

侧面拨柄与挂钩一体连接臂通过矩形榫胶接成为同一个运动组件。挂物时挂钩和侧柄同步下降21.25mm，吐司反向上升；取下后同步复位。侧柄中心x42.8、y-2.5，空载z46.25、承重z25；机身槽高26.75、宽2.375mm，中心z35.625。插榫5.75×2×1.875mm，插入盲孔深1.6mm，每边与槽底留0.1mm，胶固后才传递运动；侧槽每边0.1875mm余隙。连接臂PETG随挂钩一体打印，需要支撑悬臂部位，实际摩擦、联动顺滑和回位需试装。

背板外皮下沿z8.375与底座上沿贴齐，外露局部竖向缝隙为0。内部低位导轨止挡与后内壁的0.2mm避让仍保留：止挡后沿y16.05、内壁y16.25；避让切除只作用于内部零件，背板外皮不会被切掉。

槽沿增加的是平面内的边带厚度，由0.9375mm增至1.875mm；竖向高度恢复原0.75mm。开口53.75×12.5mm保持，向外扩展后外形为57.5×16.25mm，底面z57.5、顶面z58.25。
